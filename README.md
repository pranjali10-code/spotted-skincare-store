# SPOTTED. ⭐
### Spots happen. We've got you.

SPOTTED. is a playful, responsive skincare e-commerce website
created as part of my Web Development Internship at Auspify Technologies.

## About the Project

SPOTTED. is a demo online store featuring a Hydrocolloid Star Patch Kit
with 36 star-shaped patches.

The website combines a colourful, modern shopping experience with
interactive elements and responsive design.

## Features

- Responsive landing page
- Product showcase with image gallery
- Interactive shopping cart
- Quantity controls and subtotal calculation
- Product removal functionality
- Checkout form with demo order confirmation
- Unique demo order ID generation
- How to Use section
- Product information and brand story
- FAQ with expandable questions
- Newsletter demo signup
- Smooth scrolling and animations
- Mobile-friendly navigation

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
4. Explore the SPOTTED. website.

## Important Note

This is a front-end demonstration project.
Checkout and newsletter functionality are simulated.
No real payments, orders or email subscriptions are processed.
